# Banking-Loan-Portfolio-Credit-Risk-Analytics
An end-to-end **Banking Loan Portfolio & Credit Risk Analytics** project using **Python, MySQL, and Power BI** to analyze loan portfolio performance, customer risk, default behaviour, overdue accounts, collateral coverage, and recovery performance.

## 📌 Project Overview

This project analyzes banking loan data to identify factors associated with **loan default risk** and evaluate the overall health of the loan portfolio. The project follows a structured analytics workflow from data cleaning and database development to statistical analysis and interactive Power BI dashboard reporting.

## 🛠️ Tools & Technologies

* **Python** – Data cleaning, preprocessing, statistical analysis & risk analysis
* **Pandas** – Data manipulation and preparation
* **MySQL** – Database creation, calculated fields & business analysis
* **SQL** – Business queries, segmentation, ranking & portfolio analysis
* **Power BI** – Data modeling, DAX KPIs, interactive dashboards & visualization

## 🔄 Project Workflow

**Raw Banking Data → Python Data Cleaning → MySQL Database → SQL Business Analysis → Python Statistical & Risk Analysis → Power BI Dashboard → Business Insights**

## 📊 Key Analysis

* Loan approval and rejection analysis
* Default rate by loan type
* Customer loan exposure
* Customer risk segmentation
* Income group vs. default risk
* Credit score vs. default risk
* Loan amount vs. default risk
* Overdue and loan aging analysis
* Loan-to-Income (LTI) analysis
* Loan-to-Value (LTV) analysis
* Collateral coverage analysis
* Loan recovery and recovery rate
* Monthly and yearly portfolio trends
* Customer and branch ranking analysis
* Correlation analysis of important financial variables

## 📈 Power BI Dashboard

The interactive dashboard focuses on:

* Total Loans
* Loan Amount
* Outstanding Balance
* Approval Rate
* Default Rate
* Overdue Amount
* Recovery Rate
* Loan Type Analysis
* Risk Category Analysis
* Aging & Recovery Analysis
* Portfolio Trend Analysis
* Branch and Customer Analysis

Interactive slicers and filters allow users to explore the portfolio by **Loan Type, Loan Status, Risk Category, Income Group, Credit Score, Loan Amount, Branch, and Year**.

## 🎯 Business Objective

The primary objective is to transform raw banking data into actionable insights that can help financial institutions improve **credit-risk monitoring, loan portfolio management, overdue tracking, collateral assessment, customer risk evaluation, and recovery strategies**.

## 🚀 Outcome

This project demonstrates an end-to-end **Data Analytics and Business Intelligence workflow**, combining Python, SQL, and Power BI to support data-driven banking decisions.
